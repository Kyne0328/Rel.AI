Manual paste tools

Use when ChatGPT returns a context request block that the inline button did not detect. Paste the full ````rel-ai-context` block or raw JSON object, then click Insert. Rel.AI will read the requested workspace files and insert them into the open ChatGPT tab.

Use when you want to apply a patch that the inline button did not detect. Paste the rel-ai-apply metadata block followed by the diff block, or paste a raw unified diff. Rel.AI will run git apply in your workspace.

Rel.AI only reads the workspace aliases and paths you choose. Patches are applied locally through Git after you review the ChatGPT response.
